Multi uart input/output software

Open source, free for any use

Reads from and write to multiple UART simulatenously (linux /dev/ttyUSB or /dev/ttyACM, windows COMxx)
Displays data, first start to come, first is displayed. Displays time when data come.

Contains 4 UARTs, but software can be simply modified for more.
